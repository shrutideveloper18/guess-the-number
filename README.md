# 🧠 Beat the Computer! – Guess the Number Game

A fun & interactive number-guessing game where the computer randomly picks a number between **1–100**, and you try to guess it!  
Get hints like **Higher / Lower**, and enjoy the win animation when you guess correctly 🎉

---

## 🚀 Live Demo 

## 🎮 Gameplay

- Enter a number between **1–100**
- Press **Check**
- Game will guide you: "Higher" or "Lower"
- Guess right → You win!
- Replay button appears to play again 🔁
